# Acceptance Criteria

## V1

### Functional
- Case 可以触发 AI Analysis
- Task 可恢复
- SSE 正常
- Yield Drop Investigation 可完成
- Evidence 可追溯
- Report 结构完整
- Engineer Feedback 可提交

### Safety
- 无生产写操作
- Tool 权限正确
- 审计完整

### Performance
- 首次输出 < 3s
- 普通 Case < 30s
- 复杂 Case < 60s

## V2

- 至少支持 5 类 Case
- Dynamic Plan 可根据结果调整
- Similar Case 可解释
- Knowledge Reference 可追溯
- Correlation 可视化

## V3

- Action 必须经过权限与审批
- 执行结果可追踪
- Verification 可运行
- 高风险动作无法绕过审批
