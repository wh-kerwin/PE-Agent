# Investigation Workflow

## Common Workflow

### Phase 1 Context
读取 Case 和关联实体。

### Phase 2 Scope
确定受影响对象。

### Phase 3 Timeline
建立事件序列。

### Phase 4 Change Detection
找出：
- parameter change
- recipe change
- tool state change
- alarm
- SPC/FDC violation

### Phase 5 Comparison
比较：
- before / after
- affected / unaffected
- current / historical
- tool / peer tools
- recipe version

### Phase 6 Retrieval
获取 Historical Cases 和 Knowledge。

### Phase 7 Evidence Graph
建立：
Conclusion → Evidence → Source。

### Phase 8 Hypothesis
形成多个潜在根因，并保留反证。

### Phase 9 Recommendation
生成可执行的调查建议。

### V3 Phase 10 Action
Recommendation → Action → Approval → Execute → Verify。
