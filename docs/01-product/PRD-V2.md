# PRD V2 — 嵌入式交互调查（路线图）

状态：未排期，不属于 V1 验收。继续从原 Dashboard 的 Case 行进入，Drawer 可展开更大的调查视图。

## 目标与范围

在 V1 完成 Yield Drop 证据闭环后，逐类增加 SPC Alarm、FDC Alarm、Tool Down、Lot Hold、Wafer Abnormal、Recipe Abnormal。每类须有上下文映射、只读工具、专业评估集和独立验收，不沿用一份泛化 Prompt 直接上线。

增强跨 Lot/Tool 对照、Recipe Diff、混合知识检索、可解释相似度、证据关系图。V1 已有基础关联与有限重新规划；V2 增加用户定向追问和深度多分支调查。

## 交互

工程师在当前 Case 内选择「比较其他 Tool」「验证此假设」「查看相似案例」，系统创建关联的调查轮次，保留旧报告、来源和用户新增约束。仍遵循平台权限和预算。避免将追问扩展为无边界通用聊天。

证据矩阵显示每个假设的支持、反证、未决项。例如同 Recipe 的其他设备正常，可能支持设备特异性，但不是「压力漂移」本身的反证；证据角色需结合假设定义。

## 验收门槛

按类型评估工具选择精度、专家认可率、相似案例 Precision@k、知识引用准确率与调查耗时。模型/Prompt 变更后回放旧类型数据防止退化。只有在延迟和复杂度数据证明需要时才评估多 Agent。

V2 保持制造数据只读，生产动作仍由工程师在原平台执行。
